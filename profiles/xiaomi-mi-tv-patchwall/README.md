# Xiaomi / Redmi Mi TV (PatchWall Debloat Profile)

- **Manufacturer:** Xiaomi
- **Platform:** PatchWall Android TV
- **Target SoCs:** Amlogic T962 / T972, Mediatek

## Key Benefits
- Disables aggressive PatchWall home screen ad banners (`com.xiaomi.mitv.advertise`).
- Disables telemetry analytics (`com.xiaomi.mitv.analytics`).
- Removes redundant payment and store stubs (`com.xiaomi.mitv.payment`, `com.xiaomi.mitv.shop`).
- Pairs seamlessly with Projectivy Launcher.
